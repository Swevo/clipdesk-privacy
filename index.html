ClipDesk Privacy Policy

Last updated: 2026-11-03

Summary

ClipDesk is a local screen/webcam recorder. All recording, video processing, webcam background blur, and caption generation happen entirely on your device. ClipDesk does not have its own backend server, does not send your recordings, webcam video, audio, or transcripts anywhere, and does not require an internet connection to record, edit, blur, or caption a video.

The only network communication ClipDesk performs is the standard Microsoft Store commerce API (Windows.Services.Store) used to check your Free/Pro/ Business license status and process purchases — this is Microsoft's own billing infrastructure, not a ClipDesk server, and is subject to Microsoft's own privacy statement, not this one.

What ClipDesk does NOT do

  • Does not upload your screen recordings, webcam footage, or microphone audio anywhere, ever.
  • Does not send video frames, audio, or transcripts to any cloud AI/ML service. Webcam background blur (U2NETP) and captions (whisper.cpp tiny, multilingual) both run as bundled, fully offline ONNX/GGML models on your own CPU — no network round-trip, no external inference API.
  • Does not include any third-party analytics, advertising, or tracking SDKs.
  • Does not read, transmit, or store the contents of other applications beyond what you explicitly choose to capture: a display, region, or window you record, a screenshot you take, or text you ask ClipDesk to extract (OCR) from a screenshot. Capture uses Windows' own screen/webcam capture APIs, and everything is processed locally.

Diagnostics feature (opt-in usage log, always-on crash safety net)

ClipDesk includes a "Diagnostics" menu with two related, but distinct, pieces introduced to make bug reports easier to act on:

  1. Crash reports (always on, no toggle): if ClipDesk hits an unexpected error, a JSON file describing the exception (type, message, stack trace, app version, OS version) is written to a local Diagnostics folder on your device. This file is never transmitted automatically — you must explicitly use "Copy last crash report" and paste it yourself (e.g. into a support email or GitHub issue) for anyone to see it.
  2. Local usage log (opt-in, default off): if you enable "Help improve ClipDesk" in the Diagnostics menu, ClipDesk appends short local log lines (e.g. "a recording finished successfully") to a rotating local text file on your device. As with crash reports, this file stays on your device and is never uploaded — there is currently no telemetry backend this could even be sent to. If that changes in the future (e.g. a real opt-in cloud telemetry service is added), this policy and the in-app toggle description will be updated first, and the setting will remain off by default until you choose to turn it on.

Bundled ML models

ClipDesk bundles two open-source, offline machine-learning models: U2NETP (Apache-2.0, webcam background segmentation) and whisper.cpp's tiny (MIT, offline speech-to-text for captions). Both run 100% locally on your device's CPU. Their license notices are included with the app (THIRD-PARTY-NOTICES.md).

Screenshots, OCR, and scheduled recordings

Screenshots you take and text copied from them via OCR are processed entirely on your device (offline) and saved only where you choose. If you schedule a recording, ClipDesk starts it at the time you set while the app is running; the result is saved locally like any other recording and nothing is uploaded.

Keystroke overlay (optional, Pro)

If you turn on the keystroke overlay, ClipDesk installs a system-wide keyboard hook only while you are recording with the overlay enabled. Pressed keys are shown on screen so viewers can see them, which means they appear in the recording. Keys are never logged, stored, or transmitted by ClipDesk. Because everything you type is displayed, do not type passwords or other sensitive information while the overlay is on. ClipDesk shows a one-time notice the first time you enable it.

Camera and microphone access

ClipDesk requests webcam and microphone access only to record what you choose to record (webcam overlay, or system+mic audio). Windows' own privacy settings govern whether ClipDesk can access the camera/microphone at all; ClipDesk performs no capture without an explicit user-initiated recording action, and does not access the camera/microphone in the background.

Children's privacy

ClipDesk is a general-purpose productivity tool not directed at children and does not knowingly collect personal information from anyone, of any age — because it does not collect or transmit personal information at all (see above).

Changes to this policy

If ClipDesk's data handling changes (for example, adding a real cloud telemetry backend, cloud sync, or an online captions provider), this file will be updated in the same change, and the Store listing's privacy policy link will continue to point at the current version.
